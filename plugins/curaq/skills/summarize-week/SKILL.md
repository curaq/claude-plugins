# 今週の学び

CuraQリモートMCPのツールを呼び、**サーバー側で生成済みの週次インサイトを整形表示するだけ**のスキル。
記事を自分で要約・再分析しない。

## 手順

1. `get_weekly_insight` を呼ぶ
2. 結果に応じて分岐:
   - `status: completed` → キャッシュ済みインサイトをそのまま表示
   - `can_generate: true` → `generate_weekly_insight` を呼ぶ。生成には時間がかかる場合が
     あるため、`generating` が返ったら数十秒待って `get_weekly_insight` を再確認する
   - 「今週読んだ記事がありません」等のエラー → そのままユーザーに伝える
   - 週1制限のエラー（生成済み）→ 既存のインサイトを表示する

## 出力フォーマット

```
## 🗓 今週の学び（<週の開始日>週・分析記事 <articles_analyzed> 件）

<summary をそのまま>

### 次に読むなら
- <suggestions を箇条書きでそのまま>
```

## 表示先（curaq-view がある場合）

`mcp__curaq-view__show` ツールが使える場合（curaq-view プラグイン導入時）は、上の出力フォーマットの内容を
`markdown` に入れてそれで表示し、チャットでは同じ内容を繰り返さず一言だけ返す。URL は `[タイトル](URL)` のリンクで書く。
ツールが無い、または `shown: false` が返った場合は、従来どおりチャットに表示する。

## してはいけないこと

- summaryやsuggestionsの書き換え・要約・追加
- 週1生成制限の回避を試みること（制限メッセージはそのまま提示）
