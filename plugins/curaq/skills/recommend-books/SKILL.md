# おすすめ書籍

CuraQリモートMCPのツールを呼び、**サーバー側で生成済みの書籍レコメンドを整形表示するだけ**のスキル。
自分で書籍を選定・推薦しない。

## 手順

1. `get_book_recommendations` を呼ぶ
2. 結果に応じて分岐:
   - `status: completed` → キャッシュ済みレコメンドを表示
   - キャッシュなし/期限切れで生成可能 → `generate_book_recommendations` を呼ぶ。
     `generating` が返ったら数十秒待って再確認する
   - レート制限エラー（週1回）→ メッセージを**そのまま**提示し、キャッシュがあればそれを表示
   - タグ不足エラー → 「まず記事をいくつか保存・読了すると精度が上がる」旨を案内

## 出力フォーマット

```
## 📖 あなたにおすすめの本

_ベース: <tags_used のタグ一覧>_

1. **<書名>**（<著者>）
   <推薦理由をそのまま>
   <リンクがあればそのまま>
...
```

## 表示先（curaq-view がある場合）

`mcp__curaq-view__show` ツールが使える場合（curaq-view プラグイン導入時）は、上の出力フォーマットの内容を
`markdown` に入れてそれで表示し、チャットでは同じ内容を繰り返さず一言だけ返す。URL は `[タイトル](URL)` のリンクで書く。
ツールが無い、または `shown: false` が返った場合は、従来どおりチャットに表示する。

## してはいけないこと

- ツール結果にない書籍の追加や、推薦理由の創作・書き換え
- レート制限の回避（メッセージはそのまま提示）
