# 記事のおすすめ

CuraQリモートMCPのツールを呼び、**結果を整形表示するだけ**のスキル。
記事一覧の再分析・再要約はしない（分析はサーバー側で実施済み）。

## 手順

1. `get_insights` を呼び、重み付きタグと読書統計を取得する
2. `get_discovery_queue` を呼び、未消化のdiscovery（おすすめ記事キュー）を取得する
3. キューが空なら `generate_discovery` を呼ぶ。レート制限エラー（プラン別）が返ったら、
   そのメッセージを**そのまま**ユーザーに提示する
4. 結果を以下の形式で表示する

## 出力フォーマット

```
## 📚 あなたへのおすすめ

**最近の関心タグ**: <get_insightsの上位タグを5個程度、重み順>

1. **<記事タイトル>** — <理由（ツールが返した推薦理由をそのまま）>
   <URL>
...
```

- 興味がないと言われた記事は `dismiss_discovery` で消化する
- 保存したいと言われたら `save_article` を呼ぶ

## 表示先（curaq-view がある場合）

`mcp__curaq-view__show` ツールが使える場合（curaq-view プラグイン導入時）は、上の出力フォーマットの内容を
`markdown` に入れてそれで表示し、チャットでは同じ内容を繰り返さず一言だけ返す。URL は `[タイトル](URL)` のリンクで書く。
ツールが無い、または `shown: false` が返った場合は、従来どおりチャットに表示する。

## してはいけないこと

- ツールの結果に含まれない情報の推測・創作
- 記事本文の取得や独自の再分析
- エラー・レート制限メッセージの言い換え（そのまま表示する）
